# Production release, 30 September 2026

The card-design branch was merged with the previously deployed security release
`73f9c2bcd195` before activation. This preserves security-version checks, bootstrap
password restrictions, platform-only authorization, registration concurrency,
and existing deployment safeguards while retaining free signup, customer numbers,
approval email and semantic cards. DrivingAsist controllers remain removed.

Validation: 510 backend tests pass; EF reports no pending model changes; React type
check and production build pass; Next.js production export passes; Flutter web
release builds. Production migrations were first validated against a restored
backup, and database and uploaded-file backups were taken before activation.

The API service uses a project-specific ASP.NET Core 8 runtime under
`/opt/courseintellect/dotnet8` through a systemd override. Other applications keep
their existing runtime configuration. Persistent uploads and secrets remain
outside release directories.

Public endpoints: `https://schoolasist.com` (marketing and platform administration),
`https://maydanozasist.schoolasist.com` (React application and API),
`https://maydanozasist.schoolasist.com/mobil/` (Flutter browser application).
Native iOS/Android and desktop installer distribution are separate releases.
