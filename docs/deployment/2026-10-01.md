# 1 October 2026 release preparation

This release includes the responsive SchoolAsist marketing site with eleven role
pages, animated SVG product scenes, category dialogs and the official logo. The
onboarding flow adds an encrypted durable email outbox, verified-contact approval,
receipt emails, temporary credentials and CAPTCHA-protected support/contact forms.
Registration remains free without choosing a billing package.

Local checks: 572 backend tests passed; three PostgreSQL tests correctly report
that they need isolated databases. Marketing lint and export (49 routes), desktop
TypeScript and production web build passed. Linux deployment success/failure
fixtures passed, including runtime-switch rollback. Production migrations were
rehearsed against an isolated database restored from a fresh backup, with no
pending EF model changes. SMTP certificate validation, STARTTLS and authentication
passed without sending messages; inbox delivery is not established by this check.

The server has .NET 10 installed. Deploy with
`COURSE_INTELLECT_DOTNET_RUNTIME=/usr/share/dotnet/dotnet` so the new backend uses
that runtime and rollback restores its prior runtime override. Other services keep
their runtime configuration. Persistent outbox keys are stored under
`/var/lib/courseintellect/onboarding-keys`, owned by the API user with mode 0700.
Keep these keys in restricted backups alongside the database.

Both backend and marketing must come from the exact `TARGET_SHA`. Fresh database
and uploaded-file snapshots are verified before migration and activation. Build
the React and Flutter web artifacts from the same commit, with the production API
origin and Flutter base href `/mobil/`; then switch `web-current` only after the
backend health checks pass. Native desktop installers and iOS/Android binaries
require separate distribution and are not updated by a server deployment.

The original dirty server checkout is preserved; deploy from a separate clean
checkout. Live activation and real PostgreSQL provider results are recorded after
the release checks finish, rather than inferred from the preparation steps.
